# 对话显微镜

独立、本地运行的聊天时间线工具。通过桥接模块活引用旁边 qq_chat_search/core.py，只读取用户选择的一个会话；不复制解析器、不改本体、不上传数据。通用源码纳入工具集统一版本管理，本地数据、测试及输出由白名单排除。

## 启动

需要 Python 3.10 或更新版本、Tkinter；绘图使用 Matplotlib。从本目录执行：

```cmd
python -m pip install -r requirements.txt
python -m microscope
```

也可双击 launch.cmd。--file 指定本地档案；--project-path 覆盖可信的主项目目录。默认项目位置相对本拓展解析，移动整个工具集仍可用。

## 操作

选择 JSON、JSONL、ZIP 或分块文件夹，点击读取。日期列表来自档案。上方概览默认使用按分钟统计的条形图，可通过“条形图／积分图”按钮单独切换。条形图按成员与系统堆叠显示分钟消息量；积分图分别显示从当前统计日起点起的累计比例，各以本类当天总量为分母；有数据的曲线在统计日结束处达到1，无数据时保持0。纵轴范围为0至1.2，只标注0至1的刻度，顶部留白。切换保留观察范围与消息选择，时间线继续独立展示。勾选“手动选范围”后，可以拖选时段并在下方滚轮缩放；点击点查看正文及前后各三条记录。可手动输入 HH:MM 或 HH:MM:SS，结束边界不包含该时刻，自然日模式下24:00表示日末，非自然日模式下次日04:00表示日末；点击全天恢复。

成员时间线使用右侧纵向滚条浏览，行数随画布高度自动变化，每行保留约30像素空间；在名称区域滚轮也可滚动成员。下方横向滚条平移当前时间范围。长昵称在坐标轴内省略，原文面板保留完整名称。窗口和图文分隔条可自由调整，启动大小会适配屏幕。当前范围超过2500个可见点时，切换到按分钟、名称聚合的密度图，放大后可以点击单条消息。密度点大小表示消息量。左侧列表显示当前范围的前300条，不受成员滚动影响；图中可以点击列表之外的消息并查看原文。

成员名称直接显示导出记录中的姓名或昵称，不做匿名化。系统消息依据导出器 system=true 或 type=system 的明确元数据识别，集中在 [系统通知] 行，以橙色绘制；成员消息使用青色。概览分别统计两类消息，列表增加类型列，系统记录也以橙色显示。默认不显示系统消息，勾选“显示系统消息”后加入统计和时间线；原文上下文仍保留相邻系统通知并注明类型。

当前成员行按导出显示名称分组，同名者会合并，改名者可能分行。导出及图片识别、回复关系推断暂未实现。公开项目仅包含通用源码和说明，测试只用合成消息，不附带用户数据或个人配置。

读取失败保留已有数据；后台线程只读取和建立索引，主线程更新界面。图表依赖不可用时，时间输入框、消息列表、上下文仍可操作。程序不自动保存原文、截图、缓存或输出文件。

“非自然日模式”默认不勾选，按东八区00:00至次日00:00统计；勾选后改为04:00至次日04:00。横轴、条形图、积分分母和日期分组同步变化，原文时间保持实际时间。跨午夜时标注“次日”。

“手动选范围”默认关闭，展示完整统计日。勾选后启用开始/结束输入、概览拖选、时间缩放及横向时间滚条；取消后恢复全天。成员纵向滚动和消息查看始终可用。
