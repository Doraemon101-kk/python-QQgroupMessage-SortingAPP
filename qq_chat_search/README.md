# 本地群聊检索器

双击 `launch.cmd`，或在本目录执行 `python app.py`。需要带 Tkinter 的 Python 3.10 或更新版本，无第三方依赖，不会上传聊天记录。

1. 选择 QQ Chat Exporter 的普通 JSON、JSONL、ZIP，或通过“选择文件夹”选分块导出目录，再点击“读取文件”。输入路径由你选择，也可以通过 `--file` 参数指定；不再假定文档目录或 OneDrive 的位置。
2. 填发送者、关键词，选择“全部命中”或“任意命中”；需要限制时间时，分别选择开始和结束日期，再点击搜索。发送者、关键词和日期默认留空。
3. 点击结果，下方查看全文和上下文；可用上下文数调整范围（前后各 0—20 条）。
4. “导出全部命中”保存 Markdown，保存位置由你选择；不再自动创建或依赖程序目录下的 exports 文件夹。可用普通文本编辑器打开，导出包含所有页面。

发送者在导出中的昵称、群名片、QQ 号字段中匹配，支持部分名称。正文中的 @ 和转发作者不算该消息的发送者。若要找转发里提到某人的消息，把名字放在关键词里。

关键词不区分英文大小写；用空格分开的多个词，默认须全部出现；“任意命中”只需出现其中一个。空关键词在两种模式下都不限制正文。导出会记录实际搜索使用的模式，即使搜索后切换下拉框也不会错误标注旧结果。两项留空显示全部消息。每页 200 条，按北京时间先后排列。上下文会包含其他人、系统消息和图片占位，图片内容不识别。当前版本不合并多个不同群的档案，支持日期范围筛选。

读取时跳过无法解析的行并统计；支持 JSON 顶层消息数组或对象中的 messages 数组；ZIP 会自动识别 JSONL 分块或单个消息 JSON，忽略 manifest.json。多个会话目录或多个普通 JSON 暂不自动混合。导入失败会说明原因并保留上次成功加载的数据，界面单独显示当前来源与跳过条数。程序保留正文和少量元数据以便检索，大档案需要相应内存。

批量导出示例（在本目录运行，替换输入路径）：

```powershell
python app.py --file "聊天记录.zip" --sender "示例用户" --keywords "实习" --context 3 --output "检索结果.md"
```

代码入口：`core.py` 负责读取、搜索、上下文及导出；`app.py` 负责桌面界面。可以先从修改摘要长度或关键词匹配规则开始理解代码。

命令行任意命中：在上述命令中增加 `--any` 即可，例如 `--keywords "实习 offer 面试" --any`。

## 安装与运行

需要 Python 3.10 或更新版本及 Tkinter。当前仅使用标准库，`requirements.txt` 没有第三方依赖条目。

```powershell
python -m pip install -r requirements.txt
python app.py
```

## 本地数据与 Git 提交

聊天记录、昵称、QQ 号、路径和截图可能含个人信息。数据在本机处理，项目不自带聊天数据。

`.gitignore` 使用根目录文件白名单，只允许运行代码、启动脚本及本说明和依赖说明。`data/`、`exports/`、缓存、虚拟环境、密钥、日志、截图及压缩包默认都被忽略。新增公开源码文件时需要主动加入白名单。

测试文件仅供本地使用，不包含在公开版本中。提交时仍需检查差异，避免把真实聊天内容或密钥写进已允许的源码和说明文件。忽略规则不会移除已经跟踪的文件；不要使用 `git add -f` 绕过规则。

导出器界面只显示 JSON 时直接选 JSON 导出即可，无需自己压缩或改后缀。普通 JSON 会整体加载，大文件建议使用分块 JSONL。当前更新尚不含拖拽、多文件合并或快捷键。

## 日期筛选

开始、结束日期默认不限。点击“选择日期”打开日历牌，通过年、月下拉框或左右箭头切换，再点击某一天。日历固定提供 2020-09-01 至 2027-05-24（包含两端）；年份和月份选项随边界收缩，范围外的日期按钮禁用，自动处理不同月长和闰年。范围包含起止当天，统一按北京时间计算；前后文可越过筛选范围。起点晚于终点会提示并保留旧结果。导出记录最后一次成功搜索时的日期。

命令行示例：`--start-date 2026-09-01 --end-date 2026-09-30`。该范围限制日历可选日期；“不限日期”不施加时间限制，命令行仍允许指定范围之外的有效历史日期。


## 日历版本更新

- 年、月下拉框与左右翻月按钮配合使用，每月可直接点选具体日期；已选日期用方括号标记。
- 日历覆盖 2020-09-01 至 2027-05-24，超出边界的日期不可选；点击“不限日期”清空对应条件。
- 日期筛选可与发送者、关键词及全部／任意命中模式组合，结束日期包含当天 23:59:59。
- 导出使用最后一次成功搜索的条件；只修改日历而未重新搜索，不会改变已有结果的导出条件。
- 界面初始化按文件选择、搜索条件、日期、分页和消息展示拆分，方便继续维护；仍无第三方依赖。

在桌面界面预设日期（选择文件后点击读取）：

```powershell
python app.py --start-date 2026-09-01 --end-date 2026-09-30
```

按日期批量导出（替换为自己的本地文件）：

```powershell
python app.py --file "聊天记录.zip" --keywords "示例关键词" --start-date 2026-09-01 --end-date 2026-09-30 --output "检索结果.md"
```
